# Shubham Jha Portfolio v3

A fresh Vite + React implementation of the v3 portfolio direction. The previous portfolio project is not modified.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Main editable files

- `src/main.jsx` — content, projects, hero states and sections
- `src/styles.css` — full design system, motion and responsive rules
- `public/img/` — documentary imagery, project art and hero artifact images
- `public/reports/` — downloadable field report
